Descripción del sistema

SCAN-SIGHT I.A. es una plataforma SaaS EASM (External Attack Surface Management) desarrollada por Wayweb. Permite a cualquier empresa escanear dominios de clientes y prospectos, descubriendo subdominios expuestos, puertos abiertos y certificados SSL problemáticos — y entregando un reporte profesional de riesgo en minutos.

Los hallazgos técnicos son procesados por Google Gemini 2.5 Flash (generativelanguage API · API Key) para traducirlos a riesgo de negocio comprensible: impacto operacional, plazo de resolución recomendado (SLA) y resumen ejecutivo en español. La arquitectura es completamente serverless sobre Google Cloud Functions + Firestore + Cloud Storage, con un frontend en React + Vite servido desde scan.wayweb.cl (CloudPanel en GCP VM).

El modelo comercial opera en dos verticales (sector público y sector privado) con un catálogo de cuatro niveles: Tier 0 — informe de cortesía gratuito enviado por Wayweb al prospecto sin exponer la herramienta; Tier 1 — servicios puntuales one-shot (diagnóstico completo, plan de remediación, reporte normativo ISO 27001 / Ley 21.663, reporte ejecutivo para directorio); Tier 2 — monitoreo continuo por suscripción mensual (planes Starter, Business, Pro, Enterprise); Tier 3 — consultoría y proyectos de seguridad (talleres, políticas, acompañamiento de cierre de hallazgos, auditoría normativa); Tier 4 — white-label y acceso API para MSPs e integradores que quieran ofrecer EASM bajo su propia marca. El ticket promedio proyectado por cliente en el primer año oscila entre $890.000 y $2.5M CLP.

Lógica de análisis de hallazgos

El analyzer recibe delta_events y genera contexto de riesgo de negocio:

# Vertex AI Analyzer — Evaluación de riesgo
def analyze_finding(finding: dict) ->
  prompt = build_risk_prompt(finding)
  response = gemini.generate(prompt)
  if response.risk_level == "CRITICAL":
    return sla_hours=2, alert=True
  return sla_hours=48, alert=False

Solo los hallazgos con state_hash diferente al escaneo anterior son enviados a Gemini, reduciendo el costo de inferencia en escaneos sin cambios.
